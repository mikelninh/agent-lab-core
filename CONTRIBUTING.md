# Contributing

Thank you for helping improve Agent Lab Core.

1. Open an issue describing the environment, failure mode, or API change.
2. Keep changes game-independent and deterministic.
3. Add a seeded reproduction and an exact replay test for bug fixes.
4. Run `npm test` before opening a pull request.
5. Do not submit proprietary game data, secrets, telemetry, or personal information.

By contributing, you agree that your contribution is licensed under Apache-2.0.
